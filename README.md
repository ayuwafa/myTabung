# myTabung 🌷

Duit tersusun, hati tenang.

Aplikasi web ringkas untuk mengagihkan baki bank ke dalam beberapa "tabung" (simpanan bertujuan) dan menjejak baki bebas dibelanjakan.

- Data disimpan dalam browser (localStorage) sahaja — tiada sambungan ke akaun bank.
- Gunakan **Backup** / **Pulihkan backup** untuk memindahkan data (fail JSON).

Laman: https://ayuwafa.github.io/myTabung/
